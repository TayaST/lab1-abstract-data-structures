## Описание

Реализация структур данных на C++:
- массив (строки),
- односвязный список (строки),
- двусвязный список (строки),
- стек (строки),
- очередь (строки),
- бинарное дерево поиска (BST) с проверкой на полноту.

Все структуры — именованные (можно создавать несколько экземпляров одного типа),
данные сохраняются в файл формата `имя : содержимое`.
